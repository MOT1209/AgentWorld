# Blender asset scripts

The 3D models in `apps/web/public/models/` are generated by these scripts, never
edited by hand. Change a script and re-run it to change a model.

| Script | Output | What it builds |
|---|---|---|
| `characters.py` | `character.glb` | Stylized chibi character: named animation pivots, four hairstyles, baked outlines |
| `common.py` | – | Shared helpers: mesh builder, role materials, outline hull, GLB export, preview renders |

## Run

**Headless (no Blender install), using Blender as a Python module.** This needs Python 3.13:

```bash
python3.13 -m venv .venv-blender
.venv-blender/bin/pip install bpy==5.2.2
.venv-blender/bin/python tools/blender/characters.py \
  --out apps/web/public/models/character.glb --preview /tmp/previews
```

**With a desktop Blender (5.x):**

```bash
blender -b -P tools/blender/characters.py -- --out apps/web/public/models/character.glb
```

**With Blender MCP:** open Blender with the MCP add-on running and ask your assistant to
execute `tools/blender/characters.py`. Then look at the model in the viewport and tweak
the constants at the top of the script.

`--preview DIR` writes Cycles renders of each hairstyle (front and three-quarter views).
Outlines are hidden in previews because Cycles has no back-face culling.

## Contract with the web app

`apps/web/src/world/characterFactory.ts` relies on:

- Empties named `torso`, `head`, `armL`, `armR`, `legL`, `legR` as animation pivots,
  with legs and torso parented to the root and arms and head parented to the torso.
- A torso mesh named `chest` (widened per build variant) and hair meshes `hair_0`…`hair_3`.
- Materials named by role: `skin`, `hair`, `top`, `bottom`, `shoes`, `eye`, `white`,
  `blush`, `accent`, `outline`. The app recolours them per agent with cel-shaded
  materials, so colours set in Blender are previews only.
- `*__outline` meshes are inverted hulls, rendered back-face only.

`tests/world-character-model.test.ts` checks the committed GLB against this contract. If the
model is missing or fails to load, the app falls back to its procedural figure.
